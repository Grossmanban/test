# Домашняя бухгалтерия

Личный планировщик бюджета в рублях: доходы и расходы, остаток после каждой операции,
лимиты по категориям и цель накоплений. Устанавливается на iPhone и iPad как приложение,
работает без интернета и синхронизирует данные между устройствами через ваш собственный
бесплатный проект Supabase.

**Открыть:** <https://grossmanban.github.io/test/>

## Установка на iPhone и iPad

1. Откройте адрес выше в **Safari**.
2. Нажмите **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → **«Добавить»**.
3. Запускайте «Бюджет» с экрана «Домой»: приложение откроется без панелей браузера и будет работать офлайн.

При первом запуске показан пример бюджета за прошлый и текущий месяц. Кнопка
**«Удалить пример»** убирает его, ваши собственные записи при этом остаются.

## Синхронизация iPhone ↔ iPad

Без настройки данные хранятся только на устройстве. Чтобы вести один бюджет на нескольких
устройствах, подключите бесплатный проект Supabase (без своего сервера):
**[пошаговая инструкция](supabase/README.md)**, около 10 минут. Коротко:

1. Создайте проект на <https://supabase.com>, выполните [`supabase/schema.sql`](supabase/schema.sql) в SQL Editor.
2. Впишите адрес проекта и публичный ключ в [`config.js`](config.js) (или введите их в приложении).
3. В приложении нажмите значок облака → **Создать аккаунт** на одном устройстве и **Войти** на остальных.

Пока нет сети, всё сохраняется на устройстве и отправится, когда связь появится. При
одновременной правке одной записи на двух устройствах побеждает более поздняя правка.

## Что внутри

| | |
|---|---|
| Интерфейс | `src/app.html`, `src/app.css`, `src/app.js`: один код для PWA и для версии на claude.ai |
| Хранилище PWA | `src/store-pwa.js`: IndexedDB на устройстве + синхронизация с Supabase |
| Окно синхронизации, установка, обновления | `src/pwa.js`, `src/pwa.css` |
| Офлайн-режим | `src/sw.js` (service worker), `src/manifest.webmanifest`, `public/` (иконки, шрифты, supabase-js) |
| База данных | `supabase/schema.sql`: таблицы, правила доступа RLS, «последняя правка побеждает» |
| Версия для claude.ai | `src/store-artifact.js` → `dist/artifact/budget.html` |
| Контракты между частями | [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) |

## Разработка

Нужен только Node.js 20+, зависимости не устанавливаются.

```sh
node tools/build.mjs                 # dist/pwa (сайт) и dist/artifact/budget.html
node tests/e2e/serve.mjs             # локально: http://127.0.0.1:8787/test/
node --test tests/store-pwa.test.mjs # синхронизация и хранилище
bash tests/schema/run.sh             # схема Supabase на временном PostgreSQL 16
node tests/e2e/pwa.e2e.mjs           # сквозная проверка PWA в Chromium (нужен Playwright)
```

Каждый пуш в `main` собирает сайт и публикует его на GitHub Pages
(`.github/workflows/pages.yml`; в настройках репозитория **Pages → Source: GitHub Actions**).

Иконки интерфейса — подмножество [Lucide](https://lucide.dev) (`node tools/icons-subset.mjs`),
шрифты Manrope и Unbounded (OFL), supabase-js (MIT): см. [`public/LICENSES.md`](public/LICENSES.md).
